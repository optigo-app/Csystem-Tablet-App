# GEMINI.md

> **Mandatory Workflow:** **Always create a detailed implementation plan before writing any code.** Understand the requirement, analyze the existing codebase, read all relevant files, search for similar implementations and reference files, identify dependencies, affected modules, risks, and edge cases, then present a step-by-step implementation plan. **Do not start coding until the plan is complete (and approved if required).** Reuse existing patterns instead of creating new ones, avoid assumptions, keep changes minimal and consistent with the project architecture, and validate all changes before marking the task complete.
